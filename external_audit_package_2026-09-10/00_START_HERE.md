# Autonomous Scientist external audit working package

Package date: 10 September 2026

This package contains the current manuscript, figures, prospective protocols,
development-only results and the exact frozen software archive for an independent
pre-execution audit. It is intended for an auditor who has no prior knowledge of
the project.

## Purpose of the project

The manuscript asks what must be true for a research agent to become an
autonomous scientific programme. It defines **autonomy closure** as the ability
to carry a root objective through research selection, discovery, prospective
testing, recovery and evidence-governed resolution without unrecorded scientific
intervention. The implemented architecture has six closure conditions:

1. Goal closure uses a dynamic AND/OR graph to decompose a broad objective into
   falsifiable leaves and integrate local results into parent decisions.
2. Search closure maintains controlled alternatives through an implemented
   reference portfolio of incremental, de novo and delayed-hybrid discovery.
3. Epistemic closure fixes predictions, admissible evidence and decision rules
   before target outcomes are exposed.
4. Recovery closure assigns distinct transitions to infrastructure,
   implementation, protocol, measurement, scientific-null and
   representation-exhaustion failures.
5. Claim closure separates proposal, validation and promotion authority.
6. Operational closure uses a hash-chained ledger and causal memory to preserve
   actions, evidence, failures, costs and experiment identity across restart.

The current frozen experiment isolates recovery and claim authority. It asks
whether authority separation improves valid scientific progress when the
foundation model, methodological instructions, public task, tool surface and
resource budget are matched. It does not establish end-to-end autonomy closure
or estimate the independent value of goal decomposition and controlled search.
A separate prospective end-to-end protocol is included for context but is not
part of the present audit decision.

## What the external auditor is being asked to do

The immediate request is a pre-execution audit of the frozen authority archive. The auditor
must work from a fresh extraction on a machine and account controlled by the
auditor. The audit has two parts:

1. Recompute integrity anchors and run the automated audit.
2. Inspect the six human-review domains: answer separation, matched resources,
   interruption semantics, statistical implementation, ablation isolation and
   provider sequestration.

If every automated and human check passes, the auditor may issue the public
`external-audit-release.json`. If any item fails, the auditor must report the
failure and must not authorize provider execution.

The auditor is not being asked to assess or authorize the separate end-to-end
autonomy-closure study, run the 540-episode frozen experiment, or generate study
tasks at this stage. Confirmatory task generation and model execution begin only
after a valid audit release exists.
