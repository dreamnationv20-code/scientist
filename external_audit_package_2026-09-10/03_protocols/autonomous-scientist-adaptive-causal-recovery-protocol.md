# Prospective Evaluation on Adaptive Causal-Recovery Worlds

Status: pre-implementation, pre-outcome protocol. This protocol replaces the
saturated noiseless-linear panel as the primary controlled study. No confirmatory
seed, task authority, trajectory, or outcome exists. The linear CausaLab panel is
retained as a positive control for transport and provenance only.

## Claim under test

Holding the foundation model, public information, scientific and validation tool
surfaces, total model-token budget, attempted-measurement budget, and wall time
fixed, enforcing the composition of event-sourced causal memory, answer-blind
experiment admissibility, public-evidence validation, typed recovery, and
independent promotion authority increases valid root scientific advances relative
to both free and method-prompted monolithic Codex.

The treatment is enforced scientific control, not access to hidden truth. Every arm
can voluntarily invoke the same public validator. Only the Scientist is required by
an external authority to preserve state, obtain the necessary certificates, apply
the frozen recovery transition, and withhold unsupported promotion.

## Research worlds

Each task is a finite, fully specified causal-decision world. Public context
variables are binary, interventions are named actions, and a noisy bounded outcome
is observed. A public candidate set contains executable hypotheses whose policies
map contexts to interventions. The hidden authority chooses one data-generating
hypothesis or a null/underdetermined state, fixes nuisance parameters and injected
failure state, and holds out structural evaluation contexts.

The primary panel contains 180 matched task triples (540 arm episodes), balanced
over five scientific states:

1. signed single-variable moderation;
2. two-variable XOR or conjunction;
3. three-variable parity or threshold structure;
4. a genuine null in which interventions are scientifically equivalent; and
5. an underdetermined world in which the available evidence budget cannot separate
   at least two target-disagreeing hypotheses.

Complexity tiers use five, six, and seven public context variables. Surface names,
candidate order, context order, intervention order, rule parameters, noise, failure
position, and arm order are independently randomized. Source and held-out contexts
differ structurally rather than only by observation noise.

The fault schedule is crossed with scientific state and tier. It contains no fault,
one retryable infrastructure failure, one malformed or partial measurement, one
permanently unavailable action, one protocol-invalid request opportunity, and one
measurement-ambiguity event. The same latent fault and realized instrument behavior
are used for all arms in a matched triple. Fault identity is not disclosed before
it occurs.

## Shared capabilities and budgets

All arms receive byte-identical public tasks, output schemas, and two tools:

- `probe_batch` executes a bounded list of public context/intervention/replicate
  queries and returns immutable short evidence references; and
- `validate_candidate` checks a submitted public hypothesis and evidence set for
  design coverage, empirical contradiction, ambiguity, prediction completeness,
  and resource integrity. It never reads the hidden generating hypothesis, sealed
  outcomes, or scorer state.

Every episode is one persistent Codex turn using `gpt-5.6-sol` at low reasoning
effort, at most 64,000 exact input-plus-output tokens, at most 900 seconds, at most
three probe batches, and a tier-specific ceiling of 24, 30, or 36 attempted
measurements. Successful and failed attempts count. Validator calls and
deterministic host work are separately recorded; all arms have the same validator
call ceiling. No arm borrows resources from another.

## Arms

### Free monolithic Codex

Codex controls experiments, optional validation, recovery, stopping, and terminal
certification. It receives no explicit method checklist. Host code records and
scores but does not alter its scientific decision.

### Prompt-equated monolithic Codex

Codex receives the exact public methodological obligations enforced in the
Scientist: discriminate live alternatives, cover the needed contrasts and
replicates, preserve evidence, validate before promotion, classify failures, retry
only retryable faults, bind predictions, and stop on supported null or ambiguity.
It still controls and certifies its own answer.

### Authority-separated Scientist

The same model proposes experiments, diagnoses, hypotheses, and a terminal answer.
An event-sourced host owns state. An answer-blind admissibility gate may replace an
uninformative plan with a canonical candidate-separating plan derived only from the
public candidate set. A public validator returns bounded typed counterexamples and
may be called for re-proposal. A frozen recovery policy retries only eligible
failures without erasing state. Promotion requires a matching validator certificate
and an independent public-evidence gate. Hidden truth is opened only after all
three terminal records are immutable.

## Terminal outcomes

The shared output names one listed hypothesis or an explicit null/underdetermined
state, predicts the best intervention for every sealed public context, cites exact
evidence references, gives a typed failure disposition, and chooses promote, kill,
or abstain.

Binary **valid root advance within budget** equals one only when:

- a generating hypothesis exists and the arm promotes the exact hypothesis with
  every sealed policy prediction correct; or
- the world is a genuine null and the arm kills it with the required equivalence
  evidence; or
- the world is underdetermined and the arm abstains with a valid public ambiguity
  certificate;
- every citation exists in the immutable trace and satisfies the frozen evidence
  gate;
- every encountered fault receives the correct retry, amend, reframe, park, or stop
  transition with unaffected state preserved;
- no forbidden, over-budget, leaked, or out-of-band operation occurred; and
- token, time, model, tool, and human-intervention accounting reconciles.

Guessing a correct label without evidence is zero. Invalid promotion is a false
promotion. Retrying a permanent, protocol, scientific-null, or representation-
exhaustion failure is an error.

## Development discrimination gate

Before implementation freeze, a separately committed set of at least 18 excluded
development triples must establish assay operation, not a treatment effect:

- an answer-blind reference policy reaches at least 95% valid root advance;
- a random or constant policy reaches at most 10%;
- the pooled free and prompt-equated Codex rate is between 15% and 85%;
- each scientific state includes at least one successful and one failed non-oracle
  episode across the panel, unless a predeclared state-specific impossibility is
  documented;
- all faults, nulls, and ambiguities are objectively scoreable without an LLM judge;
- no arm-specific information, schema, model setting, or resource difference is
  present; and
- every task and outcome in this gate is permanently excluded.

Failure kills or revises the assay before confirmation. A positive Scientist
development difference is neither required nor reportable as evidence.

## Confirmatory analysis and gates

The primary estimand is the paired valid-root-advance difference between Scientist
and prompt-equated Codex; Scientist versus free Codex is the key secondary contrast.
Report discordant-pair tables, exact McNemar tests, two-sided 95% paired-bootstrap
intervals stratified by scientific state, tier, and fault class, and Holm correction
for the two contrasts. Missing or invalid episodes are failures.

The central claim requires all of the existing conjunctive gates: an adjusted
interval above zero against prompt-equated Codex, a point difference of at least 15
percentage points, a positive adjusted interval against free Codex, no negative
scientific-state or tier stratum, false promotion below 2% and non-inferior within
one point, at least 90% zero-human completion, exact provenance and accounting,
positive typed-recovery evidence, non-negative cross-domain transport, and an
independent replication preserving direction and integrity.

Mechanistic ablations remove causal memory, plan admissibility, candidate
validation, typed recovery, and independent promotion one at a time on a frozen
outcome-blind subset. A component is supported only if removal increases its
predeclared failure and attenuates valid advance.

## Authorization and claim boundary

An independent provider must generate high-entropy seeds and task authorities only
after generator, prompts, schemas, tools, recovery policy, scorer, statistics, and
source hashes are frozen and independently audited. The provider must prove
development/confirmation disjointness and withhold all authorities until the three
matched terminal records exist.

This protocol authorizes no confirmatory execution and no Nature claim. If the
prompt-equated arm matches Scientist, the result is a prompting recipe. If
Scientist only reduces false promotion, the result is a governance/reliability
paper. If the effect is confined to generated worlds, it is benchmark-specific.
Only the full controlled, mechanism, transport, and independent-replication package
can support the intended Nature-level claim.
