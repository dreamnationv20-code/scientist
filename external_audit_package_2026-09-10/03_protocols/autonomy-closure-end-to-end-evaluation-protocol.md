# Prospective end to end autonomy closure evaluation

Status: design specification for a separate future freeze. This protocol is not
part of implementation freeze
`27a53ce49129ca44dd45f1120241b5b7e7c4674759f95666ec714c42e0bdce95`, does
not authorize task generation or model execution, and is not included in the
current auditor's release decision.

## Scientific question

Can the complete Autonomous Scientist convert a broad, previously unseen
research objective into an independently defensible terminal conclusion without
out-of-band scientific intervention, and does it do so more often than the same
foundation model operating as a matched standalone research agent?

The study separates two outcomes:

1. **Autonomy closure** means that every scientific decision after launch occurs
   through the registered system or is recorded as an external dependency.
2. **Scientific advantage** means that the closed system produces more
   independently validated root advances within the matched resource budget.

Autonomy closure is necessary but does not by itself establish scientific
advantage.

## Unit of evaluation

The unit is a sealed research programme. Each programme begins with:

- a root objective and measurable success criterion;
- a public scientific context and admissible prior information;
- a finite token, tool, compute and wall-time budget;
- a set of domain instruments and their public contracts;
- prospective stopping conditions; and
- a private evaluation authority held outside both research arms.

The programme does not begin with a predefined sequence of experiments. The
evaluated system must choose and revise subgoals, originate candidate
explanations, design and execute discriminating tests, integrate local results
into parent decisions and produce a terminal boundary.

## Experimental arms

### Complete Scientist

The complete system uses the evolving goal graph, prospective lifecycle,
controlled discovery channels, causal memory, typed recovery, independent
validation and promotion authority, and durable receipts. The foundation model
has proposal authority only.

### Prompt equated standalone agent

A persistent standalone agent receives the same scientific obligations in its
prompt but controls its own state, recovery, validation and terminal
certification.

### Free standalone agent

A persistent standalone agent receives the public objective, tool contracts and
output schema without the additional method policy.

All three arms use the same model snapshot, reasoning setting, public inputs,
tool surface, token ceiling, wall-time ceiling, compute ceiling and evaluator
access. The comparison is invalid if one arm receives hidden task information,
more instruments, post-outcome repair or uncounted human work.

## Primary endpoint

The primary endpoint is **independently validated root advance within budget and
without out-of-band scientific intervention**.

A terminal record counts only when all of the following are true:

1. the conclusion changes the registered root scientific state;
2. the conclusion is supported by the private evaluation authority or satisfies
   the registered conditions for a null or justified abstention;
3. every cited observation and artifact exists in the immutable trace;
4. local results satisfy their parent integration rules;
5. failure dispositions and resource accounts reconcile; and
6. no unregistered human or external-model scientific decision occurred after
   launch.

Activity, manuscript production, a locally improved score and a correct guess
without supporting evidence all score zero.

## Scientific intervention accounting

An intervention is scientific when it changes the live question, causal
representation, hypothesis set, experiment design, interpretation, recovery
class, stopping rule or claim boundary. Routine infrastructure supplied through
a preregistered service contract is not scientific intervention. Every external
request and response receives an immutable receipt, actor identity, timestamp,
resource charge and authority classification.

The following events fail autonomous closure unless the episode contract
prospectively defines them as legitimate terminal dependencies:

- a person or Codex chooses the next subgoal or successor mission;
- an external actor repairs scientific code by introducing a new mechanism;
- a person interprets an ambiguous result for the system;
- a hidden evaluator reveals outcome information before terminal commitment;
- an author waives a failed validation or changes a stopping rule; or
- state is reconstructed from conversation rather than authoritative records.

## Secondary outcomes

- false-promotion and unsupported-claim rates;
- exact resume rate after scheduled interruption;
- correct classification of infrastructure, implementation, interface,
  protocol, measurement, scientific-null and representation-exhaustion events;
- repeated-equivalent-experiment rate;
- orphaned external-effect and unaccounted-compute rates;
- information gain per normalized total cost;
- human or external-model intervention minutes;
- time and cost to valid root resolution;
- goal-graph revision quality and parent-integration completeness; and
- prospective hypothesis diversity under common evaluation.

## Domain panel

The study will include fresh generated causal worlds and prospective
computational research programmes in at least three distinct domains. The
initial candidates are formally verified compiler optimization, database or
systems optimization, and small-model learning or tool-use mechanisms.

Domain packs may change instruments, local artifact schemas and private
evaluators. They may not change the universal kernel, authority separation,
memory semantics, failure policy, intervention accounting or promotion rules
after the first eligible outcome is exposed. Results will be reported by domain
before any pooled analysis.

## Targeted mechanism removals

The preregistration will select an outcome-blind subset for one-at-a-time
removals of:

1. evolving goal-graph revision;
2. controlled search diversity;
3. semantic causal memory and experiment equivalence;
4. typed recovery and successor selection; and
5. independent claim authority.

Each removal must preserve the foundation model, public information, tools and
resource ceilings. A mechanism is supported only if its removal reduces the
primary outcome and increases the failure class it is intended to control.

## Success gates

A broad scientific-advantage claim requires every following condition:

1. the paired root-advance difference between Complete Scientist and the
   prompt-equated standalone agent is positive and its preregistered 95%
   confidence interval excludes zero;
2. the point estimate is at least 15 percentage points;
3. no declared domain has a negative point estimate;
4. false promotion is non-inferior to the prompt-equated arm and below 2%
   overall;
5. at least 90% of Complete Scientist episodes require no out-of-band scientific
   intervention;
6. every action, model call, tool call, artifact, external effect and resource
   charge is linked to authoritative state; and
7. an independent execution site reproduces the direction of the primary effect
   and all validity gates on disjoint tasks.

The exact task count, stratification, confidence construction, non-inferiority
margin and multiplicity procedure must be fixed through simulation and power
analysis before eligible task identities or outcomes exist.

## Failure and downgrade rules

- If the prompt-equated standalone agent matches the complete system, the result
  supports a scientific-method prompt rather than autonomy architecture.
- If the complete system closes programmes but does not improve valid root
  advance, report operational autonomy without scientific advantage.
- If false promotion worsens, no advantage claim is permitted regardless of
  productivity.
- If only one domain succeeds, report a domain-specific result.
- If an ablation does not attenuate its target failure, do not attribute the
  effect to that component.
- If independent replication fails, do not make the broad central claim.

## Freeze and independence requirements

Before execution, a new content identity must bind the task contract, model
snapshot, prompts, system source, domain packs, intervention taxonomy, resource
accounting, scoring code, analysis code, ablation subset rule and downgrade
language. An independent provider must generate eligible tasks and retain private
authority until all matched terminal records are immutable. A separate auditor
must establish information separation, resource matching and analysis fidelity
for this new freeze.

The current external audit may inform this later audit but cannot authorize it.
