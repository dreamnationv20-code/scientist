# Independent audit request

Thank you for reviewing this project. You do not need any prior conversation or
project history. This document states the scientific boundary and the decision we
need from you.

## The decision requested

Please determine whether the frozen package is fit to proceed to independent task
provision and confirmatory execution. A pass means that the code and prospective
protocol implement the declared answer separation, matched comparison, failure
handling, statistical analysis and release boundary. A pass does not endorse the
manuscript, predict a positive result or certify scientific novelty.

The manuscript now presents the broader architecture as a theory of autonomy
closure. Your current decision remains narrower: audit the frozen matched study
of recovery and claim authority. The file
`03_protocols/autonomy-closure-end-to-end-evaluation-protocol.md` describes a
future study and is explicitly outside this release. Please do not treat it as a
modification of the frozen protocol or as an additional audit obligation.

Please issue `external-audit-release.json` only if every required automated and
manual check passes. If one check fails or cannot be verified, return the audit
materials with a clear finding and do not issue the release.

## Independence requirement

The auditor may be an ML researcher, research software engineer, statistician or
audit organization. The auditor must not have implemented or tuned this system,
must not have helped select its development outcomes and must use a separately
controlled machine or account. Any relationship to the authors or proposed task
providers must be disclosed in the attestation.

## Important boundaries

Do not modify the archive or silently repair a failure. Do not create confirmatory
seeds, tasks or private authorities before the audit release. Do not accept
author-supplied task answers as evidence that answer separation works. Do not run
the full model experiment during this audit.

The automated audit is intentionally repeatable and uses no language-model calls.
It requires Python, `uv` and local CPU execution. A Codex account or access to the
frozen foundation model is not required for the pre-execution audit. Model access
is required only if the auditor later agrees to serve as the independent task
provider or execution site.

## Materials to return

Return the completed attestation, observed archive digest, environment record,
automated audit output, external audit release if authorized, and a findings log.
The exact filenames appear in `RETURN_CHECKLIST.md`.
